# 🌸 Data Classification Using AI — DecodeLabs Project 2

## 📌 Objective
Build a classification model using the Iris dataset 
to predict flower species using KNN algorithm.

## 🗂️ Dataset
- Name: Iris Dataset (built-in scikit-learn)
- Samples: 150 (balanced)
- Classes: 3 (Setosa, Versicolor, Virginica)
- Features: 4 (Sepal Length, Sepal Width, 
              Petal Length, Petal Width)

## 🧠 Algorithm Used
K-Nearest Neighbors (KNN) with K=5

## 📊 Results
- Accuracy: ~97%
- Evaluated using Confusion Matrix & F1 Score

## ⚙️ How to Run
Open classification.ipynb in Jupyter and run all cells.
